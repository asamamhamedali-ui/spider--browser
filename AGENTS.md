# Spider Browser Agent Instructions

Read `docs/ENGINEERING_RULES.md`, `docs/SECURITY.md`, `docs/ARCHITECTURE.md`, and `docs/ACCEPTANCE_CRITERIA.md` before implementing features.

This repository is an early scaffold. Do not imply browser, transfer, background, persistence, media or AI functionality exists unless implemented and tested.

Before changes:
- identify milestone and acceptance criteria
- inspect existing code and avoid replacing files unnecessarily
- propose the minimal implementation
- keep native bridge interfaces typed and secure

After changes:
- run typecheck/tests where available
- document any missing test
- update acceptance checklist
- list changed files and exact run commands
- state limitations honestly
